# Crypto Users — Email Addresses

A collection of email addresses associated with crypto users, intended for legitimate research, analysis, and outreach.

## Purpose

This project is intended to support research and analysis related to the cryptocurrency community, including understanding audience trends and communication patterns.

## Responsible Use

- Use the information only for lawful and legitimate purposes.
- Respect applicable privacy and data-protection laws.
- Do not use the data for spam, harassment, phishing, or other abusive activities.
- Respect opt-out and removal requests.
- Avoid sharing or publishing sensitive personal information unnecessarily.

## Disclaimer

Users of this project are responsible for ensuring that their use of the information complies with applicable laws, regulations, and privacy requirements.
